# Моделирование концепта «любовь» с помощью FastText и ModernBERT

Репозиторий содержит код и экспериментальный пайплайн к выпускной квалификационной работе
«Сравнительный анализ классических и современных методов моделирования концепта “любовь” на материале англоязычного и русскоязычного романа XX века».

**Общая характеристика проекта**
Проект посвящён сравнению статических подсловных эмбеддингов FastText и контекстуализированных представлений ModernBERT / RuModernBERT при моделировании лексико‑семантического поля концепта «любовь» в двух художественных текстах:
- Д. дю Морье, «Ребекка» (английский язык)
- М. А. Булгаков, «Мастер и Маргарита» (русский язык)

В репозитории реализован полный цикл обработки: от предобработки корпусов и извлечения эмбеддингов до кластеризации и визуализации семантических полей.



В работе используются модели:
- deepvk/RuModernBERT-base
- answerdotai/ModernBERT-base
